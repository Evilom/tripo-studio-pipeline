# 当前 Chrome 的网页自动化链路

适用：用户要求复用现有已登录 Chrome 和原 Tripo 标签页，不启动另一浏览器、profile 或登录会话。此时不要运行会启动专用浏览器的 CLI；使用当前会话的浏览器工具和 `extension/` 助手。扩展不是私有 Tripo API 客户端。

## 一次配置与日常执行

原目录升级、同一扩展重载、Chrome 正常确认新增站点/下载权限属于一次配置。不要卸载、另装第二份或清空账本。磁盘版本、Chrome 实际加载版本和真实功能验收分别记录。

日常流程由 Agent 完成：读取任务与共享预算 → 实际看参考 → 上传并核对方向与解码完成 → 核对当前 URL/模型 UUID/版本/设置 → 读取上传后实时报价 → 保存提交意图 → 点击一次公开付费按钮 → 核对原任务与扣费 → 检查模型 → 几何/重拓扑/UV → 贴图及后处理 → 绑定 → 动画 → 免费导出 → 自动接续下载 → 文件/贴图/动作验收 → 打包。扩展只提供防重与网页入口，不宣称是已全部验收的无人值守队列。

导出设置由可见网页操作配置。`0.5.1` 在模型页自动显示“自动导出并保存一次”：先保存同一模型/标签页/文件名的短时关联，再点一次公开 Export。后台接续已观察到的原生文件地址，通过 Chrome downloads API 保存，接口接受后回到原模型页。Agent 从页面读取扩展状态并检查实际文件；用户不需要逐件复制 UUID、保存或返回标签页。

## 输入与游戏用途

- 多视图应展示同一物体，旋转相机时保持比例、纹样、尾巴连接和空间方向一致。左侧图的画面左右与角色的解剖左右分开核对；背图尾巴遮挡躯干时先记录未知结构，不保证重建正确。
- 四足基础模型使用四爪着地、头颈与脊柱自然对齐的中立姿态；人形使用干净 T/A pose。角色身份特征与幼态比例按本次规格核对，不能用普通猫或历史资产替代。
- 上传成功后才记录最终报价。空输入价格不作提交依据。8K、PBR、面数与高低模版本分别确认；游戏用途按实际资源需求选择，先保留原高模。
- Studio 原生 Quad 面数与 GLB 三角数不是同一指标。记录网页原生结果、实际导出三角数、顶点、材质和逐张贴图尺寸。

## 恢复与坑点

导出可能把原工作标签页导航到 CDN，并触发 `ERR_BLOCKED_BY_CLIENT` 或调试连接未附着。先保留任务及设置，不重新生成、不再付费。扩展自动下载是正常 Chrome 接口；不关闭保护、拦截规则或接受危险下载。若仍被拒绝，保留失败状态，按正常浏览器流程恢复。

URL 安全确认失败与网页 DOM 控制断线是两个不同问题。使用连接工具规定的正常恢复路径，遇到明确安全停止结束当轮 Computer Use；不能用原始 CDP、Cookie、私有接口或自制后台点击器绕过停止。自动下载扩展不授予 Agent 绕过控制工具安全门禁的权限。

0.5.0 的 SPA sender.url 会停留在旧文档地址，0.5.1 改为对照内容脚本的当前路径与 Chrome 实际标签页地址，并在保存后、点击前再核对路径和设置。旧记录与付费账本保留。无纹理模型仅有 Format，0.5.1 不再强制要求不存在的 Texture Resolution；FBX 适配预设、OBJ 顶点色、骨骼和 in-place 分别记录，不能按开关位置混读。

Studio 有两种已实测的导出路径：导航到允许的 CDN 时，扩展通过正规 Chrome API 接续并返回原页；静态 GLB/OBJ 直接以 Studio Blob 下载时，0.5.1 在自己的文件名及两分钟提交窗口内，被动关联唯一已有下载编号，不再次下载。已实测补回旧静态 GLB 与 OBJ 的编号和 complete 状态。只查询本轮已记录文件；未知来源或多项匹配不自动关联，不接受任意 Blob 发起下载。

下载事件可能未送达而文件已在 Downloads。先查实际文件、时间、大小和 `.crdownload`，不要按事件超时再次导出。Chrome complete 不等于文件内容通过；同名文件以实际 Chrome uniquify 名称为准。签名 URL 会过期，查询参数不入持久/公开日志；必要时在原模型免费重新导出，不能重新生成。

数值框填入不一定立即提交给组件；按 Enter 或结束编辑后，对照滑条 aria-valuenow 与画面确认实际值。页面刚导航/刷新时，等待模型、输入计数和付费按钮真正就绪，不能只看输入框.value。

保存或应用操作也可能消耗积分。测试中 Magic Brush 和 Paint Mode 的早期余额/报价显示不足以确认最终开销，Save 后刷新才看到变化。记录点击前后余额和实际差额；费用不明时先核实并预留授权预算，不能依靠“没有价格”推断免费。

Magic Brush Gen 模式先生成满意的当前视角预览，选中预览后刷到模型，再 Save；不要把刷预览当成生成蒙版。见[官方教程](https://www.tripo3d.ai/blog/how-to-use-magic-brush)。保持相机视角，先检查预览再涂局部，最后刷新和文件检查。

## 文件检查

```powershell
python scripts/verify_glb_motion.py '完整路径/model-walk.glb' --require-animation
```

该只读诊断检查 GLB 容器、嵌入 buffer/贴图、三角数、绑定 joint/weight 属性、动画通道及时间曲线，不修改资产或验收状态。要求动画时必须有绑定节点或关节的实际变化关键帧，不能用无关节点运动加静态关节曲线蒙混通过。报告 varyingBindingChannels；它是保守的直接绑定目标检查，不等价于完整曲线求值或场景变形验证。外部依赖、除已支持 FB_ngon_encoding 元数据之外的 primitive 扩展及稀疏 accessor 明确返回未支持，不报完整通过。视觉比例、四肢变形、尾巴运动、根运动和游戏导入仍需实际观察。

真实参考、账号、模型、任务 ID、签名下载地址和项目截图留在资产项目；公共仓只发布通用代码、脱敏说明及检查范围。所有功能验收完成前不要发布“全流程已跑通”。
