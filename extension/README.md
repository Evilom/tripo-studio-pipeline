# Tripo 当前标签页助手

MV3 扩展，使用当前已登录的 Chrome 标签页。不会启动浏览器、创建登录资料、调用私有 API 或自动购买积分。安装和重载保留 `chrome.storage.local` 中原有的任务账本；不要卸载后重装，也不要另装第二份来重置预算。

## 更新原扩展

原来从本地目录加载的扩展应更新该目录，再到 `chrome://extensions` 重载同一个扩展，核对实际显示的版本为 **0.5.1**。磁盘文件更新不等于 Chrome 已更新。

0.4.0 新增 `downloads` 权限，供 Chrome 正规下载接口使用。Chrome 可能要求用户重新启用扩展或确认新增权限。它只保存从当前活动标签页读取的 Tripo 原生 `tripo_convert` GLB/ZIP，不读取 Cookie、浏览器登录资料或任意本地文件。代码不会修改网络拦截规则、关闭安全浏览、调用 `acceptDanger` 或自动放行危险文件。

`downloads` 是浏览器授权能力，应用内的 URL 白名单是代码限制；不是 Chrome 提供的权限粒度。请在实际已安装版本和代码审查后决定是否授权。

0.5.0 新增两个明确的站点授权：`https://studio.tripo3d.ai/*` 与 `https://tripo-data.rg1.data.tripo3d.com/*`。它们让扩展读取跨域导出的标签页地址，并在模型页自动显示可由浏览器自动化操作的导出控件。不使用所有网站、全局浏览历史、Cookie、debugger 或网络拦截权限。升级可能需要用户在 Chrome 正常确认站点权限，这是一次安装配置步骤；日常生产不需要用户逐件复制编号或保存文件。

## 自动接续原生导出

Agent 在原模型页正常配置 Export 后，点击页面新增的“自动导出并保存一次”。扩展读取当前模型 UUID、文件名、格式、分辨率、骨骼和动作数量，先保存一次性记录，再点击唯一的免费 Export 按钮。设置变化或按钮存在歧义时不执行。

原标签页随后转到已支持的 Tripo 原生 GLB/ZIP 地址时，后台自动调用 Chrome 下载接口，记录下载编号，并在接口接受后返回原模型页。只接续这一标签页、这一模型、这一文件名、两分钟内的导出；其他标签页与任意地址不会触发下载。不会创建浏览器或新标签页，不重置付费预算。

网页上的“查看自动导出记录”会显示排队、完成或中断状态。下载状态为 calling/uncertain/interrupted 时禁止自动重试；后台重启也不会重发未知请求。Chrome 仍可拦截下载或要求正常安全处理，代码不放行危险文件。如果已换到其他页面，扩展不会强制把它跳回模型页。

自动导出的签名查询参数仅供本次 Chrome API 调用，不进入持久日志。记录使用原模型 ID 和无查询的资源路径；转换产物 UUID 与原模型 UUID 分开保留。文件仍需实际核对大小、SHA256、贴图依赖、skins/joints 和 animation channels；Chrome complete 不证明动画内容正确。

当前版本 51 项离线检查通过。**带骨骼与 Walk 动画的 GLB 自动导出已真实通过**：Chrome complete、自动返回原模型页、43 关节/129 动画通道/实际变化曲线及 3 张嵌入贴图。原生 Export 导航仍复现过 `ERR_BLOCKED_BY_CLIENT`，自动下载使用正常 Chrome 接口。人形文本动作和多阶段动作的 GLB 已分别自动落盘并通过曲线检查；FBX/OBJ 原生包已保存并核对 ZIP 与材质依赖。其他功能和游戏质量逐项检查，不声称全部功能已通过。

源码包含最终设置快照、只读“检查当前设置”和下载异常脱敏补丁；这部分尚未在重载后的实际 Chrome 完成验收。前述核心链路的真实结果与最终补丁的离线检查分别记录，见[验收矩阵](../references/current-chrome.md)。

0.5.1 修复 SPA 当前路径比对、无纹理导出、FBX 预设及 OBJ 顶点色记录。直接下载的既有文件也会按已记录文件名、两分钟窗口、Studio 来源及唯一匹配被动关联 Chrome 编号；不会创建第二次下载。旧静态 GLB、OBJ 记录与新 UV 无纹理 GLB 均已真实验证。

## 付费阶段

1. 在正常 Tripo workspace 页打开助手，导入已有任务或自包含任务包。初始余额和上限沿用原任务；同一个任务不允许重新导入来提高上限。
2. 在网页配置实际输入、模型版本、面数、贴图分辨率及动作。助手支持图片输入、网页文字模型输入和文本动作；分割、UV、多阶段动作等使用“其他公开阶段”，填写实际按钮名称并手动标记。
3. 用“检查页面控件”或手动标记确认唯一余额、付费按钮和按钮内报价。不可用或歧义的按钮不会提交。
4. 读取预览，核对网页，再执行一次。预览还保存提示词、时长、模式及选择项；设置、URL、输入、余额或报价变化后重新读取。
5. 提交前先保存预算预留，点击后标为待确认。到原任务页关联模型/任务 ID 和实际扣费，再标记页面完成。没有自动重试。

“其他公开阶段”是手动可见 UI 操作入口，不是该阶段通过真实平台验收的证明。免费预览/动作应用在网页正常执行，不把报价 0 当成付费阶段。

## 导出跳到 CDN 时保存文件

网页 Export 的格式、分辨率和动画选择仍由 Tripo 管理。如果原生导出将原标签页导航到 Tripo 文件地址，打开这个扩展的工具栏弹窗：

1. 输入原模型页面的 UUID 和文件名，GLB 地址用 `.glb`，打包格式用 `.zip`。
2. 核对它确实来自本轮模型导出，勾选确认，再点“保存一次”。不要从页面中的任意链接发起下载。
3. 扩展调用 `chrome.downloads.download`，保留本页、不导航、不另开标签页。重名采用 Chrome `uniquify`，不覆盖已有原件。保存到 Chrome 默认 Downloads 目录；以实际保存文件名为准。
4. “读下载记录”显示 Chrome 下载编号与状态。下载中、已完成或结果不明的同一请求不会再次启动。签名 URL 的查询参数不进入持久记录。
5. 下载结束后回到原 Tripo 页，核对文件大小、SHA256、GLB/ZIP 结构、贴图依赖和动画内容。Chrome `complete` 不能替代模型质量或文件内容验收。

当前下载白名单只包含真实观察到的 `https://tripo-data.rg1.data.tripo3d.com/tripo-studio/YYYYMMDD/<UUID>/tripo_convert_<同UUID>.glb|zip`。新地区或新路径停止并核对，不笼统放行任意域名。URL 签名过期需要在原模型免费重新导出，不重新生成模型。

如果 Chrome 仍拦截下载，保留错误并使用正常浏览器处理流程，不关闭保护或规避拦截。工具栏手动兜底与页面自动导出分别记录验收；不要将其中一条路径的成功视为另一条路径通过。
